npm licences, checked by how you ship

AGPL matters for a SaaS, GPL matters for an app people download. licensegate reads your whole dependency tree and tells you which packages conflict with your way of shipping.

npx github:agustinnb/licensegate --mode saas --prod

  REVIEW fancy-chart@1.4.2  CC-BY-NC-4.0

A list of licence names, which is what most checkers print, doesn't tell you which of them is a problem. A GPL package is usually fine on a server you run yourself. The same package can become a problem when you ship a desktop app. licensegate applies that rule to every package, including the ones you never installed directly.

What it does

  • Reads package-lock.json (v2/v3) or node_modules.
  • Resolves SPDX expressions: MIT OR GPL-3.0 means you pick MIT. Handles WITH exceptions, old licenses arrays and loose names.
  • When package.json says SEE LICENSE IN… or nothing, it reads the package’s LICENSE text.
  • Exit code 1 in CI when something blocks your mode. --allow clears a package you have checked.
  • Writes a CycloneDX 1.5 SBOM (--sbom) and a third-party notices file with every licence text (--notices).
  • Runs offline with zero dependencies. Your code never leaves your machine.
